한글은 자음과 모음을 한 칸 안에 모아 하나의 음절 블록으로 만드는 문자입니다. 자음, 모음, 받침을 익힌 뒤 직접 글자와 단어를 만들어 보세요.

HOW HANGEUL WORKS

한글 한 글자는 하나의 음절 블록입니다

기본 구조는 초성 자음 + 중성 모음 + 선택적인 받침입니다. 모음으로 시작하는 소리도 한글에서는 ㅇ을 앞에 둡니다.

예시: ㅇ + ㅏ = 아 / ㅎ + ㅏ + ㄴ = 한 / ㄱ + ㅡ + ㄹ = 글
