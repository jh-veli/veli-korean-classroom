# Veli Korean Classroom

A personal teaching toolkit designed for live Korean lessons.

## Files
- `index.html` — page structure
- `style.css` — design and print styles
- `app.js` — Hangeul learning and card builder
- `tts.js` — Korean browser speech
- `dictionary.js` — official dictionary links
- `pdf.js` — lesson summary preview and PDF print

## Run
Open `index.html` in a browser, or upload this folder to GitHub Pages.

## PDF
The **PDF로 저장** button opens the browser print window.
Choose **Save as PDF / PDF로 저장**.

## Note
This is for personal classroom use.
